New: the SYSTEM section
- System Doctor: health dashboard, Slow PC Detective, startup analyser with undo, crash analysis, drive health (SMART/NVMe) and guided repair with DISM/SFC.
- Smart Cleaner: junk with reason and risk, a preview of the exact files, Recycle Bin by default, disk space analyser with duplicates. Cookies, sign-ins and Windows folders are never touched.
- Network Lab: ping and stability (loss, jitter), bufferbloat test with consent, bandwidth, network gaming mode measured before and after, DNS benchmark, connection repair. No registry or TCP tweaks.
- Universal Mod Scanner: Installed Mods now lists every mod - AKENO installations, your own mods, Minecraft (Fabric, Quilt, Forge, NeoForge), FiveM, BepInEx, MelonLoader, ASI, ReShade, OptiScaler - with conflict hints. Other mods stay untouched.
- Security Center: Windows Security and Microsoft Defender status, Defender scans, threat history, a security check for mods and downloads, a review of running programs. AKENO is not an antivirus and never switches protection off.
- Download protection: Microsoft Defender checks downloaded components in addition to their SHA-256 check.
- "Restore game files" on the welcome screen, also without an active license.
- Export report without paths, addresses and names.

Fixed: the Hardware Health drive table stayed empty (query refused by Windows PowerShell 5.1).

Your license, settings, games, mod backups, themes and wallpapers are kept. If the new version does not start correctly, the previous one comes back automatically.

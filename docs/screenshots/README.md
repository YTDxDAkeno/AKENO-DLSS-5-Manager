# Screenshots

Real renders of AKENO DLSS 5 Manager v1.1 (`python -m akeno --screenshot docs/screenshots`, 1920x1009 window
= maximised on a 1920x1080 screen), made on Linux with Qt's offscreen platform using **test-fixture data**
from `tools/fixture_home.py --gpu rtx5090` — a synthetic RTX 5090 / 1440p system, synthetic game folders and
fixture benchmark sessions. They show the interface, not measurements from a real PC, and no real NVIDIA
runtime was present (so the install wizard correctly shows the runtime as missing).

Screenshots from a real Windows runner (100 % and 150 % scaling; that runner has no NVIDIA GPU) are attached
to every CI run as the `windows-test-results-and-screenshots` artifact.

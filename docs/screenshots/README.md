# Screenshots

Real renders of AKENO DLSS 5 Manager (`python -m akeno --screenshot`), made on Linux with Qt's offscreen
platform using **test-fixture data** from `tools/fixture_home.py` — a synthetic RTX 3080 / 1440p system
and synthetic game folders. They show the interface, not measurements from a real PC. Screenshots from a
real Windows runner are attached to every CI run as the `windows-test-results-and-screenshots` artifact.
